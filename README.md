# 5D Intelligence Framework (Android)

This is an Android rewrite of the 5D Intelligence Framework, originally a static HTML web application. It features a completely native implementation of the multidimensional correlate system and the IMP calculator using Kotlin and Jetpack Compose.

## Features
- **Theoretical Exploration:** Detailed visualization of the 5 dimensions of intelligence (Neurobiology, Psychology, Philosophy, Economy, Technology).
- **Thermodynamic Analysis:** Insights into the energetic costs of cognitive dissonance.
- **IMP-Modell Calculator:** An interactive validation tool allowing users to adjust sliders for Authenticity, Autonomy, Resilience, and Systemic Stress to compute their Integrated Multi-Potential score.

## Architecture
- 100% Kotlin
- Jetpack Compose for the UI
- Material Design 3 guidelines
